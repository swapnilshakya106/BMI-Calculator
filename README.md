# BMI Calculator 

A simple BMI (Body Mass Index) calculator built using HTML, CSS,
and JavaScript.

## What it does

- Takes weight (kg) and height (cm) as input
- Calculates BMI using the standard formula
- Shows the BMI value along with the category (Underweight,
  Normal, Overweight, Obese)
- Changes result color based on the category

## How to run

1. Download the `bmi_calculator.html` file
2. Open it directly in any browser (double click the file)
3. Enter your weight and height, then click Calculate

## Tech used

- HTML5
- CSS3
- JavaScript (DOM manipulation, event listeners)

## Formula used

```
BMI = weight (kg) / (height (m) * height (m))
```
